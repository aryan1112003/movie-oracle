# 🎬 Movie Oracle

![Movie Oracle Banner](https://images.unsplash.com/photo-1489599849927-2ee91cede3ba?auto=format&fit=crop&q=80&w=1200&h=400)

A magical AI-powered movie recommendation engine that helps you discover your next favorite film. Built with React, TypeScript, and Google's Gemini AI.

## ✨ Live Demo

Experience Movie Oracle live: [Movie Oracle App](https://fanciful-crumble-2edb25.netlify.app/)

## 🎯 Features

- 🎭 Filter by genre, mood, era, and language
- 🤖 AI-powered recommendations using Google's Gemini
- 🌙 Beautiful dark theme with glass morphism effects
- 📱 Fully responsive design
- ⚡ Lightning-fast performance with Vite
- 🎨 Modern UI with Tailwind CSS
- 🔍 Detailed movie information including ratings and plot summaries

## 🛠️ Tech Stack

- **Frontend Framework**: React with TypeScript
- **Styling**: Tailwind CSS
- **AI Integration**: Google Generative AI (Gemini)
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Deployment**: Netlify

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/aryan1112003/movie-oracle.git
   cd movie-oracle
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

4. Build for production
   ```bash
   npm run build
   ```
